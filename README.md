# Mohamed Ait Ouahmane — Portfolio

Personal portfolio showcasing decentralized systems engineering work, Bitcoin-native DApps, DeFi protocols, and full-stack projects.

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS
- **Animations:** Motion (Framer Motion)
- **Email:** Resend
- **Deployment:** Cloudflare (OpenNext)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view in browser.

## Pages

| Route | Description |
|-------|-------------|
| `/` | Home — introduction and featured work |
| `/labs` | Projects — professional, open-source, and experiments |
| `/trace` | Career timeline and engineering journey |
| `/resume` | Professional resume (downloadable as PDF) |
| `/ping` | Contact form |

## Environment Variables

| Variable | Description |
|----------|-------------|
| `RESEND_API_KEY` | API key for Resend email service (contact form) |
